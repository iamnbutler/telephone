First release of Telephone, a CLI and MCP server for messaging between local coding agents.

- Discover Claude Code and Codex sessions on the same machine.
- Send messages through Claude Code's peer socket or Codex's native queue.
- Fall back to a filesystem inbox when native delivery is unavailable.
- Use `list_agents`, `send_message`, and `check_inbox` over MCP.

## Downloads

Choose the archive for your machine. No Rust installation is needed.

| System | Archive |
| --- | --- |
| macOS 11+, Apple Silicon | `telephone-aarch64-apple-darwin.tar.gz` |
| macOS 11+, Intel | `telephone-x86_64-apple-darwin.tar.gz` |
| Linux, x86-64 | `telephone-x86_64-unknown-linux-musl.tar.gz` |
| Linux, ARM64 | `telephone-aarch64-unknown-linux-musl.tar.gz` |

Extract the archive, put `telephone` on your PATH, and run `telephone install`
for runtime setup instructions. Windows is not currently supported. Linux
binaries are statically linked with musl. macOS binaries are ad-hoc signed,
not Developer ID signed or notarized; macOS may require explicit approval.

`SHA256SUMS` contains the SHA-256 checksum for each archive. Check the downloaded
file with `shasum -a 256 <archive>` on macOS or `sha256sum <archive>` on Linux
and compare it with the matching entry before extracting it.

This is experimental software. Runtime internals may change, queued delivery
does not confirm that a message was read, and peers do not grant permissions.
