Hardening fixes for local agent messaging.

- Replace the file inbox with a transactional SQLite journal. Failed output and
  interrupted reads leave messages pending; replies retain their ancestry.
- Validate addresses and message limits, restrict state-file permissions, and
  quote peer content as untrusted data.
- Bound native delivery and subprocess output, clean up child processes, and
  report uncertain sends without automatically retrying them.
- Bound discovery, report partial results, and distinguish verified liveness
  from inferred recency. Exact addresses have a separate lookup.
- Add MCP input/output deadlines and bounded queues. Ping and cancellation stay
  responsive while a tool runs; cancelled inbox reads roll back.

## Upgrade

```sh
cargo install telephone --version 0.1.1 --locked
```

Or download the archive for macOS or Linux, ARM64 or x86-64. Verify it against
`SHA256SUMS` before extracting. macOS binaries are ad-hoc signed, not notarized.

Restart all Telephone MCP processes after upgrading. Do not mix old file-inbox
readers with the new journal. Legacy inbox files are imported and preserved;
replies to older native messages absent from the journal are refused.

Unsafe, experimental software. Use at your own discretion, on your own machine.
Cancellation cannot recall a sent message, and output is not a read receipt.
Hard worker-shutdown bounds, diagnostic-output bounds and storage quotas remain
open work. Do not expose Telephone to external clients. See
[SECURITY.md](https://github.com/iamnbutler/telephone/blob/v0.1.1/SECURITY.md).
