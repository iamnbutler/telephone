OpenCode, Zed and Delta can now register per-thread polling inboxes over the CLI
or MCP. Registration and send results explain how to receive expected replies.

OpenCode also supports opt-in native delivery to an existing authenticated local
session. It preserves the recorded agent/model selection and falls back to the
inbox only before sending; uncertain native sends are never retried automatically.
Desktop 1.18.31 passed real idle, busy and polling-fallback tests. Native setup is
explicit and manual; see the [OpenCode guide](https://github.com/iamnbutler/telephone/blob/v0.1.3/docs/opencode-native.md).

`telephone doctor` distinguishes configured native routes from reachability.
The docs site now includes OpenCode setup and the desktop test results.

```sh
cargo install telephone --version 0.1.3 --locked
```

Or download an archive below and verify it against `SHA256SUMS`. macOS binaries
are Developer ID signed and notarized; Linux binaries are statically linked.
Extract `telephone`, put it on your PATH, and run `telephone install` for setup.
Restart existing Telephone MCP processes after upgrading.

Unsafe, experimental software. Use at your own discretion, on your own machine.
