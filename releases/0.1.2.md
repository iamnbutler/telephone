macOS binaries are now Developer ID signed and notarized, for Apple Silicon and
Intel. Linux binaries remain statically linked. No messaging behavior changes.

```sh
cargo install telephone --version 0.1.2 --locked
```

Or download an archive below and check it against `SHA256SUMS`. Extract
`telephone`, put it on your PATH, and run `telephone install` for setup.

Restart existing Telephone MCP processes after upgrading.

Unsafe, experimental software. Use at your own discretion, on your own machine.
